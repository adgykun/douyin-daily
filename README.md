## 🚀 零基础小白 10 分钟手把手部署教程

### 第一步：项目 Fork 入库（把代码复制回你家）

1. 登录你的 [GitHub 账号](https://github.com)（没有的话点击 Sign up 注册一个，完全免费）。
2. 在当前项目页面右上角，找到并点击 **【Fork】** 按钮（图标像一个小叉子 🍴）。
3. 在弹出的页面中直接点击绿色的 **【Create fork】**。
4. 几秒钟后，页面会跳转到你个人账号下的项目仓库，此时代码已经成功复制到你名下啦！

---

### 第二步：准备 6 个核心配置参数

为了让特工知道要把东西搬去哪、怎么登录抖音以及怎么联系你，我们需要准备以下 6 个参数：

| 参数名称 | 作用说明 | 填写示例 |
| :--- | :--- | :--- |
| `WEBDAV_URL` | 你的网盘 WebDAV 服务器地址 | `https://dav.jianguoyun.com/dav` |
| `WEBDAV_USER` | 你的网盘账号（邮箱/用户名） | `your_email@example.com` |
| `WEBDAV_PASS` | 你的网盘 WebDAV 应用专属密码 | `xxxxxx` |
| `FEISHU_WEBHOOK` | 飞书机器人的消息推送链接 | `https://open.feishu.cn/open-apis/bot/v2/hook/...` |
| `DOUYIN_COOKIE` | 抖音网页版的登录凭证 | `passport_csrf_token=...; sessionid=...` |
| `DOUYIN_URL` | 想备份的抖音博主主页链接 | `https://www.douyin.com/user/MS4wLj...` |

以下是获取每个参数的大白话图文指导：

---

#### 1. 获取网盘参数（以【坚果云】为例，也支持 NAS / Alist）

1. 注册并登录 [坚果云官网](https://www.jianguoyun.com)。
2. 点击右上角**个人头像/昵称** -> 点击 **【账户信息】** -> 切换到 **【安全选项】** 选项卡。
3. 找到 **【第三方应用管理】**，点击 **【添加应用】**，应用名称填 `抖音备份`，点击完成。
4. 此时页面会生成应用专属密码：
   - `WEBDAV_URL` 填：`https://dav.jianguoyun.com/dav`
   - `WEBDAV_USER` 填：你的坚果云注册邮箱
   - `WEBDAV_PASS` 填：刚才生成的应用专属密码（注意：不是坚果云网页登录密码！）

---

#### 2. 获取飞书机器人 `FEISHU_WEBHOOK`

1. 打开电脑端 **飞书** 客户端。
2. 创建一个你自己的专属小群（或者在现有的群里）。
3. 点击群聊右上角的 **【...】（更多）** -> **【群设置】** -> **【群机器人】** -> **【添加机器人】**。
4. 选择 **【自定义机器人】**，名称填 `抖音备份特工`，点击 **【添加】**。
5. 复制生成的 **Webhook 地址**，这就是 `FEISHU_WEBHOOK`。

---

#### 3. 获取抖音 `DOUYIN_COOKIE`（电脑端 & 手机端超详细指南）

Cookie 是系统访问抖音时的身份凭证。你可以选择通过**电脑端**或**手机端**快速获取：

##### 💻 方式一：电脑端通过 `Cookie-Editor` 插件获取（最推荐）
1. 打开电脑浏览器（Chrome / Edge / Firefox 等）。
2. 在浏览器扩展商店搜索并安装 **Cookie-Editor** 插件（或者在 Chrome 开发者模式下安装）。
3. 打开并登录 [抖音网页版](https://www.douyin.com)。
4. 点击浏览器右上角扩展栏里的 **Cookie-Editor** 按钮。
5. 点击插件底部的 **【Export】** 按钮 -> 选择 **【Export Header String】**（或者直接在列表中全选复制 Header 里的 Cookie 字符串）。
6. 复制出的整段文本即为 `DOUYIN_COOKIE`！

##### 📱 方式二：手机端通过狐猴浏览器微软插件商店获取
1. 在手机应用商店下载并安装 **狐猴浏览器 (Lemur Browser)**。
2. 打开狐猴浏览器，点击底部工具栏的“插件/扩展”图标，进入 **微软 Edge 扩展商店 (Microsoft Edge Add-ons)**。
3. 在插件商店搜索 **`Cookie-Editor`** 并点击“获取/安装”。
4. 在狐猴浏览器中访问并登录 [抖音网页版](https://www.douyin.com)。
5. 登录成功后，点击狐猴浏览器菜单里的 **Cookie-Editor** 扩展图标。
6. 点击 **Export** 按钮，选择导出 Cookie 字符串，直接粘贴复制出来即为 `DOUYIN_COOKIE`！

##### ⌨️ 方式三：电脑 F12 开发者工具手动获取
1. 在电脑浏览器打开 [抖音网页版](https://www.douyin.com) 并登录。
2. 按 **F12**（Mac 电脑按 `Cmd+Option+I`）打开开发者工具 -> 切换到 **【网络/Network】** 面板。
3. 按 **F5** 刷新页面，点击任意请求 -> 在右侧 **【Headers/标头】** 中找到 `Cookie:`。
4. 复制 `Cookie:` 后面的全部长字符串即可。

---

#### 4. 获取博主主页链接 `DOUYIN_URL`

1. 打开抖音网页版或手机 App，进入你想备份的博主主页，复制主页链接。
2. **超级智能容错**：本工具已全面升级链接清洗引擎！你可以直接粘贴手机 App 复制的整段分享口令（如“7.12 复制打开抖音... https://v.douyin.com/...”），也可以同时填入多个博主链接，中间用空格、换行或逗号隔开，系统会自动提取合法网址！

---

### 第三步：将参数填入 GitHub 密钥与变量（Secrets / Variables）

1. 进入你在第一步 **Fork 到自己账号下** 的仓库页面。
2. 点击仓库顶部的 **【Settings】**（设置）。
3. 在左侧菜单找到 **【Secrets and variables】** -> 点击 **【Actions】**。
4. **设置敏感密钥（Repository secrets）**：点击 **【New repository secret】**，依次添加：
   - `WEBDAV_URL`
   - `WEBDAV_USER`
   - `WEBDAV_PASS`
   - `FEISHU_WEBHOOK`
   - `DOUYIN_COOKIE`
5. **设置普通变量（Repository variables）**：点击 **【Variables】** 选项卡 -> 点击 **【New repository variable】** 添加：
   - `DOUYIN_URL`（填入博主主页链接）

---

### 第四步：一键手动运行与验证

1. 点击仓库顶部的 **【Actions】** 选项卡。
2. 如果页面提示 *"Workflows aren't running on this forked repository"*，点击绿色的 **"I understand my workflows, go ahead and enable them"** 启用工作流。
3. 在左侧选择 **`douyin-daily`** 工作流。
4. 点击右侧的 **【Run workflow】** 按钮开始运行！
5. 稍等 1~3 分钟，当看到出现绿色对勾 **`✔`** 时：
   - 你的飞书群会收到一条带着酷炫 Emoji 的特工巡逻战报 🤖！
   - 打开你的网盘，能看到自动建好的 `douyin/博主昵称/` 目录，视频、图集、Live Photo、封面和头像都静静躺在里面啦！

从此以后，GitHub 每天会在 **6 点、10 点和 18 点**（06:17、10:23、18:37 错峰调度）全自动帮你巡逻备份，你只管安心看 30 套随机切换的酷炫战报就好！🎉

## 💻 本地运行教程（开发者或本地部署）

如果你想在自己的 Windows / Mac / Linux 电脑或者 NAS 上直接运行：

1. **环境准备**：安装 Python 3.8+ 与 ffmpeg（用于 1080P 验证）。
2. **拉取代码与安装依赖**：
   ```bash
   git clone https://github.com/你的用户名/douyin-backup.git
   cd douyin-backup
   pip install -r requirements.txt
   playwright install chromium
   ```
3. **配置环境变量并启动**：
   ```bash
   export DOUYIN_COOKIE="你的Cookie"
   export DOUYIN_URL="博主主页链接"
   export WEBDAV_URL="网盘地址"
   export WEBDAV_USER="网盘账号"
   export WEBDAV_PASS="网盘密码"
   export FEISHU_WEBHOOK="飞书Webhook"
   export MAX_PER_RUN="30"

   python main.py
   ```

## ❓ 常见问题与排坑指南 (FAQ)

### 1. 收到飞书提醒“抖音 Cookie 已失效”视频还能抓取吗？
* **答案**：**能！系统会自动转入降级保护模式！**
* **降级策略**：Cookie 失效后，系统依然保持既定巡逻计划，但**不再向下滚动页面**（防止下翻触发现验证码或强制登录弹窗），只保留页面首次刷新加载到的作品。
* **画质与标记**：降级模式下保存的视频，会在标题和文件名上自动标注清晰度（例如 `[720P_Cookie失效降级]`），并在记录中打上标记。
* **自动恢复自愈**：当你在 GitHub Secrets 更新了新的 Cookie 后，下一次运行系统会自动识别之前降级保存过的作品，**重新抓取一遍相同的视频**，覆盖升级为 1080P 超高清无损原画！

### 2. 网盘里的目录结构是什么样的？
文件会在你的网盘根目录下自动建立 `douyin/` 目录：
```text
douyin/
└── 博主昵称/
    ├── avatar_2026-03-24.jpg       (博主最新高清头像 1080x1080)
    ├── 2026-03-24_作品标题_video.mp4 (1080P 超高清视频)
    ├── 2026-03-24_作品标题_[720P_Cookie失效降级]_video.mp4 (降级标注视频)
    ├── 2026-03-24_图集标题_img0.jpg  (高清原图图集)
    ├── 2026-03-24_动图标题_img0_live.mp4 (Live Photo 实况动态视频)
    └── 封面/
        └── 2026-03-24_作品标题.jpg (高清作品封面)
```

## 💻 本地 Windows 部署指南（免服务器）

如果你不想使用 GitHub Actions 云端挂机，或者希望在自己的 Windows 电脑上直接双击运行，可以使用官方打包好的 Windows 本地独立运行版本：

1. **下载安装包**：前往本项目的 [Releases](../../releases) 页面，下载最新版本的 `douyin-backup-windows-x64.zip` 压缩包。
2. **解压与配置**：
   - 将下载的 `.zip` 压缩包解压到本地任意目录。
   - 在解压后的文件夹中，找到 `.env.example` 文件，复制一份并重命名为 `.env`。
   - 用记事本或文本编辑器打开 `.env` 文件，填入你的 `DOUYIN_COOKIE`、`DOUYIN_URL`、`WEBDAV_URL` 等参数并保存。
3. **首次运行预备（安装浏览器内核）**：
   - 为了控制打包体积，软件未内置几百兆的浏览器内核。
   - 请在解压目录按 `Win + R` 键，输入 `cmd` 打开命令行终端，运行以下命令（只需运行一次）：
     ```cmd
     playwright install chromium
     ```
4. **一键启动运行**：
   - 直接双击运行 `douyin-backup.exe`，或者在 CMD 中输入 `douyin-backup.exe` 启动。
   - 启动后软件会自动加载 `.env` 配置文件并开启备份流程。
5. **特别说明**：
   - 本地 Windows 版本与 GitHub Actions 云端版本功能完全一致，底层业务逻辑 100% 相同。
   - 两者共享相同的网盘目录和历史记录（`history.json`），你可以随时在本地与云端之间无缝切换。
